# Suggested 3–5 minute demo

1. **Problem and solution (20 sec):** Explain that AgriTech brings farm records, weather, soil readings, and crop inspection reminders into one place.
2. **Register/login (20 sec):** Create a farmer account and show secure authenticated access.
3. **Farm profile (30 sec):** Add a farm, location, acreage, soil type and coordinates.
4. **Crop monitoring (30 sec):** Add a crop and change its growth stage.
5. **Weather (30 sec):** Show current conditions and five-day forecast; explain that data comes from Open-Meteo.
6. **Soil health (30 sec):** Save sample test readings and explain the rule-based, non-diagnostic guidance.
7. **Pest alerts (20 sec):** Show inspection reminders and the safety disclaimer.
8. **Resources (20 sec):** Place a demo order and show order history.
9. **Community and expert consultation (30 sec):** Submit a question and consultation request.
10. **Admin (30 sec):** Log in as seeded admin; approve a post, update order status, respond to a consultation, and show summary.
11. **Close (15 sec):** Recap MERN, JWT/bcrypt, MongoDB, external weather API, and next improvements.

Before recording, use demo data only and avoid showing personal email addresses or secrets.
